# ClubLink (React SPA)

ClubLink is a campus club management and student engagement platform rewritten as a modern React Single Page Application with Vite, TypeScript, Tailwind CSS, and React Router.

## Features
- **Public Portal**: Landing page, explore campus clubs, club detail view with join request applications, events listing, about, and contact.
- **Student Portal**: Student dashboard, discover clubs, event registration, tracking join request status, AI-powered recommendations, and profile management.
- **Coordinator Portal**: Club coordinator dashboard, managing club profile/tagline, reviewing student join requests, member roster, event scheduling, and broadcasting announcements.
- **Faculty Portal**: Faculty advisor dashboard, reviewing join request approvals, campus clubs directory, coordinator assignments, and analytics/reports.

## Tech Stack
- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- React Router v7
- Lucide React Icons
- LocalStorage Persistence for Mock Database & Auth Sessions
